--- A DISCLOSED HALT ON THE FIRST ATTEMPT, AND THE REMEDY (no instrument edit) ---
The first invocation HALTED with an empty matrix. CAUSE, measured not guessed:
    RL_BUILD_LOCK_HELD=probe + RL_CONFIG_MODE=gate ->
    'UNKNOWN model override RL_BUILD_LOCK_HELD=... is not in the manifest (data/model_config.json)'
tools/build_lock.sh EXPORTS RL_BUILD_LOCK_HELD, and config_manifest.enforce() in gate mode rejects
any unknown RL_-prefixed variable as a model override. This is EXACTLY the trap PREREG_D8 §3
disclosed and docs/evidence/r23_advance_2026-08-20/recut_build.py pops in its own child env; the
bake's reseal instrument does not pop it because the bake did not run it under the lock wrapper.
REMEDY: hold the lock in the PARENT shell (the flock fd stays held, so the interlock is real) and
strip the variable from the CHILD's environment only, with env -u. The instrument is NOT edited.
SECONDARY FINDING, recorded not repaired: the instrument's own 'FAILED: no __meta__' diagnostic
path is unreachable when the matrix run dies before writing anything, because json.load() on the
empty mkstemp file raises first. That is inherited from the bake's port and from the 2026-07-17
original; fixing it is not this act's warrant. P2 item.
